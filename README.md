# Predicting Income Levels with Machine Learning

This project applies an end-to-end machine learning pipeline to predict whether an individual's annual income exceeds **$50,000** using the **UCI Adult Census Income** dataset. The workflow includes data cleaning, exploratory data analysis (EDA), feature engineering, one-hot encoding, feature scaling, model development, cross-validation, and performance evaluation.

Two classification models—**Logistic Regression** and **Random Forest**—were developed and compared using accuracy, precision, recall, F1-score, and ROC-AUC. Both models achieved approximately **85% accuracy**, with Logistic Regression producing the highest ROC-AUC (~0.90). Feature importance analysis identified **education level, capital gains, and hours worked per week** as the strongest predictors of income.

**Technologies:** Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

**Key Skills:** Data preprocessing, exploratory data analysis, feature engineering, classification, cross-validation, model evaluation, predictive analytics, and machine learning.
